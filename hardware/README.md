# hardware/ - KiCad 10 workspace

Open `GCC-Wireless.kicad_pro` in KiCad 10. Guide: [../docs/HARDWARE.md](../docs/HARDWARE.md).

| Path | What |
|---|---|
| `GCC-Wireless.kicad_sch` | Root sheet: one hierarchical sheet per item below |
| `phob/` | PhobGCC 2.0.5 schematic + PCB, unmodified upstream copy (CERN-OHL-S v2); see `phob/SOURCE.md` |
| `tx_addon.kicad_sch` | Controller add-on (TX): nice!nano v2 + Phob header J6 + battery |
| `rx_receiver.kicad_sch` | Console receiver (RX): nice!nano v2 + RP2040 bridge + GameCube plug |
| `ref_*.kicad_sch` | Reference sheets: nice!nano v2 pinout, GameCube port, RP2040 bridge pins |
| `lib/GCC-Wireless.kicad_sym` | Our custom symbols (nice!nano v2, GameCube plug, battery, Phob J6 mirror, Pico) |

The new files are generated by `build-support/gen-hardware.py` (so they can be changed in code), and are GPL-3.0 like the rest of the repo. Everything under `phob/` keeps its upstream licence, CERN-OHL-S v2.
If KiCad asks to save when you close, that is fine for our files; do not save changes to `phob/` sheets.
